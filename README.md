# Практическая работа 8

MongoDB и CRUD для заметок.

Реализованы создание, чтение, частичное обновление и удаление заметок через официальный MongoDB driver v1, как в методичке. Коллекция notes имеет уникальный индекс title. Поиск использует экранированную регулярную строку, список — limit/skip и сортировку. Ошибка дубликата возвращает 409, отсутствующего ObjectID — 404.

## Запуск на macOS или Linux

Go 1.27.1, curl, Docker Desktop. Каждая практика — отдельный Go-модуль. Команды выполняются из этой папки.

```bash
docker compose -p go-pr8 up -d
cp .env.example .env
set -a; source .env; set +a
go test ./...
go vet ./...
go run ./cmd/api
```

Файл `.env` читается оболочкой через `source`; автоматически сервер его не загружает. Порт API по умолчанию 8080. При одновременном запуске меняйте HTTP_ADDR, APP_ADDR (ПР9) или APP_PORT (ПР10).

## Проверки

Фактические результаты находятся в `evidence/`. Полные curl-команды и ответы — в `evidence/requests.txt` (для практик с HTTP-проверками). Тесты 15 и 16 записаны в `evidence/tests.txt` и `evidence/integration.txt`.

## Подготовка к защите

Документ хранит вложенные данные в BSON; коллекция объединяет документы. Модель удобна для неоднородных сущностей.

ObjectID — 12-байтовый идентификатор. В API он передаётся как 24 шестнадцатеричных символа и проверяется ObjectIDFromHex.

InsertOne, Find/FindOne, UpdateOne/FindOneAndUpdate и DeleteOne реализуют CRUD; $set изменяет указанные поля.

Уникальный индекс запрещает повтор title; duplicate key преобразуется в HTTP 409.

Контекст ограничивает ожидание сетевой операции. После дедлайна драйвер возвращает ошибку; отмена не всегда доказывает отсутствие записи на сервере.
